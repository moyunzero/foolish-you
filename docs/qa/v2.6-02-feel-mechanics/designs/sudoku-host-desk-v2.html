Host Desk：把数独做成
桌上唯一的物件

头部产品（Good Sudoku / NYT Games / Sudoku.com / 双键区流派）的共性不是「更多按钮」， 而是棋盘常驻视口、输入是贴身的仪器、笔记是一等模式。 傻了么要保留毒舌主持气质，但不能把笔记埋进折下。

设计立场：Host Desk（主持桌面） — 近黑台面、盘面是雕塑、底部是一条「机加工输入轨」。 开笔记时轨头发热（sunset），盘缘轻亮，像换了笔尖 — 而不是多一层弹窗。

相对 v1 稿改进

上一版像「把按钮排整齐」；本版有明确物件层级：盘是主体，轨是仪器，完成/认怂退到脚注级。

  • 铅笔 / 撤销 / 清除：图标按钮 + aria-label
  • 记忆点：笔记时轨头发热 + 盘缘轻描边
  • 不采用双键区（每日一局过重）
  • 无 Hint / 无一键候选

Notes · 候选

解题时的视线

记候选时仍能扫完整宫与同行 — 这是相对现状的核心胜利条件。格内笔记字号抬到约 9–10px，色比正文略淡。

  • 模式切换成本：一拍铅笔
  • 选中格 + peer 高亮保留（对照头部产品）
  • 可完成时再把「完成今日」升为白底主按钮

UI skill 对照（baseline-ui + frontend-design）

通过

  • 图标按钮具备 aria-label
  • 触控目标 ≥ 44px（数字键）
  • tabular-nums 用于计时与数字
  • 标题 text-balance / 说明 text-pretty
  • 无紫渐变、无奶油衬线模板、无多阴影卡片堆
  • 有命名美学（Host Desk），非组件拼盘

实现时注意

  • 数独页禁用盘区 ScrollView（Binary 可保留）
  • safe-area 留给底轨与认怂
  • 认怂仍走既有确认 sheet（破坏性动作）
  • 模式切换反馈 ≤ 200ms（边框/色，不动画布局）
  • 笔记字号随 cell 宽度计算，避免 8px 糊
