# 设计文档：温和成长（Gentle Growth）掌控感系统

> 状态：设计已确认，待实现。
> 范围：内容深度 / 体验打磨方向下的「掌控感」子系统。
> 红线：不破坏「每天只有一局」「离线优先」「不做独立数据看板」「招牌毒舌」。

---

## 1. 理解摘要（Understanding Summary）

- **要做什么**：在不破坏「每天只有一局」的前提下，给用户一种**温和、氛围式的「最近状态不错」**的感受，强化「我在坚持/我在变好」的掌控感。
- **为什么**：掌控感是留存抓手；但本项目要的是**非竞争、无压力**的版本，规避排行榜陷阱与「你退步了」负反馈。
- **给谁**：每日打开的老用户为主；新用户自然落入兜底（不强加成长话）。
- **关键约束**：
  - 「个人数据看板」是 out of scope → 成长感必须**织进现有界面**，不新增统计页。
  - v2.1 周节奏难度**故意不在 UI 露出难度标签** → 成长系统也不暴露难度。
  - **度量噪声**：每天换玩法 + 难度按星期爬坡，单局用时直接比是脏信号。
- **明确非目标（Non-goals）**：排行榜/好友/竞争；精确速度 PK；难度勋章；曲线图表；任何「你变慢了/你退步了」式负反馈；新增数据看板页面。

## 3. 决策日志（Decision Log）

| 决策 | 备选 | 选择理由 |
|---|---|---|
| 阶段核心方向 | 留存/增长/内容深度/同步 v3/社交 v4/打磨 | **内容深度 + 体验打磨**：契合「每天一局」，做深而非做多 |
| 掌控感内核 | 战胜过去的自己 / 里程碑 / 身份认同 / 温和成长 | **温和成长**：契合无压力品牌，规避负反馈与度量噪声 |
| 落点 | 结果页 / 月历 / 首页氛围 / 分享 | **结果页为主**（情绪峰值 + 唯一每日反馈面 + 复用现有文案层，不碰看板红线）；**月历为辅**（网格本身即温和成长可视化） |
| 信号模型 | 速度 PK / 节奏 / 混合 | **节奏为底 + 同类彩蛋 + 绝不负反馈**：节奏信号对玩法切换鲁棒，绕开脏比较 |
| ①彩蛋（同类更顺） | 本期做 / 砍 / 降级埋点 | **降级为未来项**：需迁移 + 每种玩法约一周一遇，上线后 2~3 周才可能首次触发，近期零收益。本期**只埋 `gameType` 字段，不建逻辑/UI** |
| 触达节奏 | 每日都说 / 只在值得说时说 | **只在火热/召回时说**，平常日沉默：避免唠叨，偶尔才暖显得珍贵 |
| 认怂日 | 安慰 / 沉默 | **沉默**（安慰显假），唯一例外是③召回 |
| 数字感 | 定性 / 精确数字 / 百分比曲线 | **定性为主**，最多软提「这周第 N 天」，不做百分比/曲线 |

## 4. 最终设计（Final Design）

### 4.1 第一层（主）：结果页「近况」自适应文案

- **触发时机**：结果页**完成（win）**时评估；位置在**现有毒舌文案之后、统计卡之前**（情绪曲线：毒舌 → 暖一下 → 看数据），实现时可微调。
- **判定器**：按顺序评估，**命中即停，绝不负反馈**。

| 序 | 状态 | 判定（仅用现有数据） | 文案口吻示例 |
|---|---|---|---|
| ③ | 召回回归 | 上一次完成距今 ≥ **3** 天，且今天完成 | 「好久不见，今天也来了」 |
| ②a | 火热 | 最近 **7** 天完成 ≥ **6** 天 | 「这周你几乎天天都来」 |
| ②b | 稳定 | 最近 **7** 天完成 **4~5** 天 | 「最近来得挺勤」 |
| ④ | 平常 / 新用户 | 其余情况 | **不加成长话**，沿用现有毒舌 |

- **认怂日（surrender）**：不显示成长句（保持现有毒舌）；**唯一例外**——若满足③召回条件，即使今天认怂也显示「欢迎回来」。
- **阈值**（召回 3 天、火热 6/7、稳定 4~5）为初始值，可后续调参。

### 4.2 第二层（辅）：月历月度总结改「成长口吻」

- 不改月历结构，仅改 summary 文案：由「报数字」→「叙事」。
- **只在正向时叠加成长句**（延续永不负反馈）：
  - 默认中性：「本月你来了 X 天」
  - 仅当较上月增加（N > 0）追加：「，比上月多 N 天」
- 上月完成数由现有 `entries` 计算，**零迁移**。

### 4.3 数据埋点（为未来①铺路，本期只埋不用）

- 给 `lib/storage/completionHistoryStorage.ts` 的 `CompletionEntry` 增加**可选** `gameType?: GameType`。
- `COMPLETION_HISTORY_STORAGE_VERSION` +1。
- **迁移路径**：老条目 `gameType` 保持 `undefined`（不猜测、不回填）；`normalizeCompletionHistory` 容错解析未知/缺失值。
- `recordCompletion` 新增 `gameType` 入参，调用方 `DailyGameContext` 传入今日 `gameType`。
- 配套：迁移 golden 样本 + 读写测试（`lib/storage/` 迁移红线要求）。
- **本期不实现** ① 的比较逻辑与 UI。

### 4.4 i18n

- 所有新文案走 `locales/zh` + `locales/en`，补 `en-smoke`。
- 成长文案需保持「招牌毒舌」底色（中英都要过 brand 红线）。

## 5. 风险与红线对照

| 风险 | 缓解 |
|---|---|
| 成长系统长成被砍掉的「数据看板」 | 不新增页面；只织进结果页文案 + 月历 summary |
| 暴露刻意隐藏的难度标签 | 成长信号基于「节奏/完成」，不涉及难度 |
| 度量噪声导致负反馈 | 以节奏为底；任何「更顺」彩蛋降级为未来项；绝不出现「变慢/退步」话术 |
| 文案唠叨导致疲劳 | 只在火热/召回时出现，平常日沉默 |
| 存储迁移破坏老用户进度 | `gameType` 为可选加法字段；带迁移路径 + golden 样本 + 读写测试 |
