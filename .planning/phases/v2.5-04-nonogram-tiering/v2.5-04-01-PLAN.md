## Discretion locks (Claude's Discretion → executor MUST follow)

| Topic | Lock |
|-------|------|
| File split | `techniqueIds.ts` + `lineSolver.ts` + `techniques.ts` (FullSettle) + `probe.ts` + `rater.ts` — no `techniques/` directory; no cross-type RaterBase |
| NonogramTechnique IDs | Exact: `simple_few`, `simple_many`, `probe`, `nested_probe` (D-01 / D-26) |
| TECHNIQUE_ORDER | Ascending: simple_few → simple_many → probe → nested_probe |
| peakToTier | simple_few→easy; simple_many→medium; probe→hard; nested_probe→expert |
| Easy/Medium gate | `NONOGRAM_EASY_MAX_SWEEPS = 3` — FullSettle solved + sweepCount ≤ 3 → simple_few; sweepCount ≥ 4 → simple_many. Do not retune to balance pools (D-03) |
| Sweep order | H-first (H-SWEEP then V-SWEEP alternate) — Kosters primary; no H/V averaging |
| Probe budgets | `NONOGRAM_PROBE_MAX_DEPTH = 2`, `NONOGRAM_PROBE_MAX_NODES = 800`, `NONOGRAM_MAX_TECHNIQUE_STEPS = 500`, `NONOGRAM_MAX_PRODUCTIVE_PROBES = 8` |
| Probe peak map | probeCount===1 && maxDepth≤1 → `probe`; probeCount≥2 OR maxDepth≥2 → `nested_probe` |
| Probe order | Fixed row-major unknown cells; try FILL then CROSS; no Math.random |
| Rate result | `{status:'solved', peak, tier, sweepCount, probeCount}` \| `{status:'incomplete', peak}` \| `{status:'budget_exhausted', peak}` |
| Soundness | Force only when exactly one of FILL/CROSS contradicts after FullSettle (Binary lookAhead CR-01) |
| Packages | No new npm nonogram solvers |
| Out of scope | No patterns.ts freeze; no generateForTier; no generator.ts API change; no dailySelector/hydrate; no UI badges; no force-rebalance |
