# Requirements: 傻了么 — v2.5 Adaptive Mastery

**Defined:** 2026-07-28  
**Core Value:** 用户每天打开就能玩到唯一、确定的今日谜题，并在结束时获得情绪化反馈。

## v2.5 Requirements

### Mastery model（MAST）

- [x] **MAST-01**: Each `gameType` persists independent mastery state (stability / retrievability or equivalent + last practice metadata) via storage migration + validation
- [x] **MAST-02**: On complete/abandon, mastery updates using forgetting-curve rules: success+fast raises readiness for harder tier; fail/slow/abandon and/or long gap lowers effective tier for that type
- [x] **MAST-03**: Target difficulty for a day is **primarily** from that type’s mastery tier; weekday band only nudges (≤ ±1 tier or intra-tier param nudge)
- [x] **MAST-04**: Same `dateKey` snapshot freezes the puzzle at first create; later mastery updates do not rewrite today’s board

### Technique tiers（TIER）

- [x] **TIER-01**: Shared four tiers: Easy / Medium / Hard / Expert for all game types
- [x] **TIER-02**: **Sudoku** generator+rater: Easy singles-only (givens guide ≥36); Medium pairs/locked (32–35); Hard fish/triples (28–31); Expert chains/AIC capped (≤27 guide) — **peak technique** gates acceptance
- [x] **TIER-03**: **Binary** rater gates on technique ladder (pair → balance → uniqueness → look-ahead) mapped to four tiers
- [x] **TIER-04**: **Nonogram** patterns tagged/rated into four tiers (simple sweeps → probe/look-ahead); daily pick respects target tier
- [x] **TIER-05**: **Slitherlink** rater gates on technique ladder (corner → patterns → degree/loop → bounded bifurcation) mapped to four tiers

### Diversity（DIV）

- [x] **DIV-01**: Avoid reusing recent `puzzleHash` values per type from a bounded local history ring when generating/selecting
- [x] **DIV-02**: Within a tier, generation/selection retries increase perceptible variety (shape / clue layout / pattern), with safe fallback if exhausted

### Ship safety（SHIP）

- [x] **SHIP-01**: Release notes for marketing **`2.5.0`** disclose unplayed dates may change boards after update; in-progress repair path remains protected (extend v2.4.2 SHIP-02 coverage as needed)
- [x] **SHIP-02**: Automated tests cover: mastery update math, rater tier classification fixtures, selector freeze, hash-avoid, weekday nudge bounds
